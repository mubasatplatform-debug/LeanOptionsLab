## المخاطر والحدود الانتقالية

- الإصدار الحالي يختلف عن الإصدار السابق `67e993cb965034775bb2e1a9a22804ccf6dd2775` في `docs/DATA-ACQUISITION.md` فقط؛ لم يتغير كود التشغيل بينهما.
- الحالة التشغيلية ما زالت `invalid-data`، وبالتالي لا يجوز وصفها بأنها Backtest صالح أو Paper Trading جاهز حتى تتوفر بيانات سوق مدققة وتُعتمد القواعد والتكاليف.
- محرك المختبر نفسه ليس خدمة دائمة. بوابة الحالة المنفصلة فقط تستخدم إعادة التشغيل التلقائي، ولا تشغّل المحرك.
- هذا التحقق لم يُعِد تدقيق ثغرات التبعيات، ولذلك لا يعلن أن الإصدار Security-Clean. نجاح التشغيل لا يغلق مخاطر سلسلة تبعيات LEAN.
- نتائج التشغيل محفوظة خارج رابط الإصدار في `shared/results/`؛ لا تُحذف عند التبديل أو الرجوع.

## الرجوع بعد نشر إصلاح السجل

هدف الرجوع المتحقق من وجوده ونظافته قبل نشر الإصلاح هو الإصدار الحي السابق:

```text
/opt/lean-options-lab/releases/e268a647cc42c3d990a650893294c776e8d8a985
```

يُستخدم الرجوع إذا لم يعد `current` يطابق الإصدار المقصود، أو تعذر إنتاج التقرير المرجعي، أو بقيت عملية/نقطة إصغاء بعد التشغيل. التسلسل يحضّر رابطاً مؤقتاً ثم يستبدل `current` ذرياً، ولا يحذف الإصدار الحالي أو النتائج:

```bash
root=/opt/lean-options-lab
previous=e268a647cc42c3d990a650893294c776e8d8a985

test "$(git -C "$root/releases/$previous" rev-parse HEAD)" = "$previous"
test -z "$(git -C "$root/releases/$previous" status --porcelain)"
ln -sfn "releases/$previous" "$root/current.next"
mv -Tf "$root/current.next" "$root/current"
readlink -f "$root/current"
```

بعد الرجوع، يجب أن يعيد `readlink -f` المسار الكامل للإصدار `e268a64`، ثم يُشغّل Smoke وno-data من مجلد `current` وتُراجع الحالة النهائية والأحداث والعمليات والمستمعات مجدداً.

- لم يُفعّل تداول حي أو ورقي، ولم تُرسل أوامر.
- لم تُنزّل بيانات سوق ولم تُنشأ أسرار أو اعتمادات.
